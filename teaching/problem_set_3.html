1a

Maximum likelihood by hand

Model the spring choice as a multinomial logit with common parameters on cost and time, \(V_{nj}=\beta C_{nj}+\gamma T_{nj}\). Write a function that computes utilities, the probability of each student's chosen mode, and the negative log-likelihood; maximise it with BFGS. Report estimates, standard errors, z-stats and p-values.

Theory

The likelihood. If student \(n\) chose mode \(i_n\), the probability of what we observed is \(P_{ni_n}(\theta)\). Students are independent, so the log-likelihood is

\[\ln L(\theta)=\sum_{n=1}^{N}\ln P_{ni_n}(\theta),\qquad P_{ni}(\theta)=\frac{e^{V_{ni}}}{\sum_j e^{V_{nj}}},\quad V_{nj}=\beta C_{nj}+\gamma T_{nj}.\]

The maximum likelihood estimator \(\hat\theta\) maximises it. Under correct specification it is consistent, asymptotically normal and efficient, with

\[\hat\theta\ \overset{a}{\sim}\ \mathcal N\Big(\theta,\ \big[-\mathbb E\,\nabla^2\ln L(\theta)\big]^{-1}\Big).\]

The algorithm. Optimisers minimise, so we return \(-\ln L\). BFGS climbs using the gradient and builds an approximation to the Hessian along the way. That approximation is not reliable for standard errors, so we compute the Hessian again by finite differences at the optimum (R's hessian = TRUE). The steps in the prompt map one-to-one onto the function below.

1b.i

Add alternative-specific intercepts

Again model the spring choice as a multinomial logit, now with intercepts for all but one alternative: \(V_{nj}=\alpha_j+\beta C_{nj}+\gamma T_{nj}\). Estimate by maximum likelihood and interpret.

Theory

Alternative-specific constants \(\alpha_j\) capture everything about mode \(j\) that cost and time miss: comfort, exercise, weather exposure, the hassle of parking. Only differences in utility are identified, so one constant is fixed at 0. Biking is the reference here, which is why utility_bike has no intercept.

With a full set of constants, the multinomial logit reproduces the observed market shares exactly: at the MLE, the average predicted probability of each mode equals its sample share. That is the first-order condition for each \(\alpha_j\), and the next cell checks it.

1b.ii

Are the intercepts jointly significant?

Conduct a likelihood ratio test of \(H_0:\ \alpha_{bus}=\alpha_{car}=\alpha_{walk}=0\). Do you reject? What is the p-value? Interpret.

Theory

Model 1a is model 1b with the restriction \(\alpha_{bus}=\alpha_{car}=\alpha_{walk}=0\). When one model is a restricted version of another, the likelihood ratio test compares their maximised log-likelihoods:

\[LR=2\big[\ln L(\hat\theta_U)-\ln L(\hat\theta_R)\big]\ \overset{H_0}{\sim}\ \chi^2_q ,\]

where \(q\) is the number of restrictions (here 3). Adding parameters can never lower the maximised likelihood; the test asks whether it rises by more than chance would allow.

LR is one of the "trinity" with the Wald test (Problem Set 1) and the Lagrange multiplier test. LR needs both models estimated; Wald needs only the unrestricted one. They agree asymptotically.

2a

The binary logit by method of moments

Model the winter choice as a binary logit with \(V_{nc}=\alpha+\beta C_{nc}+\gamma_{car}T_{nc}\) and \(V_{nb}=\gamma_{bus}T_{nb}\), so \(P_{nc}=1/(1+e^{-(V_{nc}-V_{nb})})\). Write the four moment conditions, a function returning the \(N\times L\) matrix of individual moments, and estimate by method of moments.

Theory

The model says the residual \(y_n-P_n(\theta)\) has mean zero given the regressors, so it is uncorrelated with any function of them. Each regressor gives one moment condition:

\[\mathbb E\big[(y_n-P_n(\theta_0))\,x_n\big]=0,\qquad x_n=(1,\ C_{nc},\ T_{nc},\ -T_{nb})',\quad P_n=\frac{1}{1+e^{-x_n'\theta}} .\]

Four conditions, four unknowns: the model is exactly identified. The method of moments (MM) sets the sample averages to zero:

\[\bar g(\hat\theta)=\frac1N\sum_n\big(y_n-P_n(\hat\theta)\big)x_n=0 .\]

These are exactly the first-order conditions of the binary logit likelihood, so MM = MLE here. The estimates should match glm() (Problem Set 2) to many decimals. (The bus time enters as \(-T_{nb}\) so that \(\gamma_{bus}\) is the coefficient in \(V_{nb}=\gamma_{bus}T_{nb}\).)

In practice we minimise \(Q(\theta)=N\,\bar g(\theta)'W\bar g(\theta)\), which is zero at the solution for any weight matrix \(W\). Standard errors come from the sandwich \(\widehat{\operatorname{Var}}(\hat\theta)=\frac1N(G'S^{-1}G)^{-1}\), with \(G=\partial\bar g/\partial\theta'\) and \(S=\frac1N\sum_n g_ng_n'\).

2b.i

GMM with instruments

Cost and time may be endogenous: a student who enjoys driving may live farther from campus. Using the instruments constant, price_gas, snowfall, construction and bus_detour, estimate the model of part (a) by generalized method of moments (four parameters, five moment conditions). Start from t0 = c(0, 0, -0.3, -0.1).

Theory

Endogeneity. If unobserved utility is correlated with cost or time, \(\mathbb E[(y_n-P_n)x_n]\neq0\) and both MLE and the MM estimator of 2a are inconsistent. Instead we use instruments \(z_n\): variables that move cost and time (relevance) but are unrelated to the unobserved taste (exogeneity):

\[\mathbb E\big[(y_n-P_n(\theta_0))\,z_n\big]=0,\qquad z_n=(1,\ \text{price\_gas},\ \text{snowfall},\ \text{construction},\ \text{bus\_detour})'.\]

Five moments, four parameters: over-identified. We cannot set all five sample moments to zero, so GMM minimises a weighted distance from zero,

\[\hat\theta=\arg\min_\theta\ N\,\bar g(\theta)'\,W\,\bar g(\theta).\]

The efficient weight is \(W=S^{-1}\), the inverse variance of the moments: precise moments get more weight. Since \(S\) depends on \(\theta\), we estimate in two steps.

Weak instruments. Gas prices barely move the cost of a short commute, so cost is identified from very little variation. The price is precision: standard errors balloon, as in the key. The first-stage cell below measures instrument strength.

2b.ii

Test the overidentifying restriction

Test whether your model is correctly specified with an overidentifying restrictions test. Report and interpret the result.

Theory

With \(L>K\) moments, the minimised GMM objective is itself a test statistic. If all instruments are valid, every population moment is zero and

\[J=N\,\bar g(\hat\theta)'\,\hat S^{-1}\,\bar g(\hat\theta)\ \overset{H_0}{\sim}\ \chi^2_{L-K}.\]

A large \(J\) means no \(\theta\) can make all moments small at once: at least one instrument is invalid, or the model is misspecified. A small \(J\) is consistent with valid instruments but cannot prove it. The test has power only against violations that make instruments disagree with one another; if all instruments are invalid in the same way, \(J\) will not notice. This is the Sargan–Hansen test.
